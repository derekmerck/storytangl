# The Salvage Yard

A small incremental-game demo: assign a worker, resolve cycles, and build a
signal fire. Run it by starting the `incremental_yard` world in a StoryTangl
client.

A finished attempt remains visible until the player chooses **Reset the yard**
or **Try again**. That choice resets the game to pending; **Run the yard**
starts the next attempt with its authored configuration. The story and journal
continue across attempts.
