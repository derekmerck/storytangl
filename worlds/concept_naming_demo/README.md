# Meeting Rin and finding Dawnblade

This executable world adopts `tangl.prose.naming` in its domain before normal
compilation. Actor defaults conceal names, location defaults display proper
names, and a concealed location overrides its class default.

Run `run_script worlds/concept_naming_demo/cli_witness.txt` from the normal
StoryTangl CLI, or run `poetry run pytest engine/tests/prose/test_naming.py`.

The introduction block emits an anonymous reference, an anonymously attributed
speaker introducing Rin, a named reference, a named speaker, and a linked choice
"Say hi to Rin". Later scenes remember the actual actor, independently of the
role that binds it. The authored graph IDs and choice identity remain stable.

`prose` is an ordered list of shared authored MuBlock/DialogMuBlock values.
`text` contains an opaque literal string, or ordered literal strings
or explicit `{ref: host, intent: auto|proper|anonymous, introduce: true|false}`
values. A dialog unit's symbolic `label` resolves before its body; set its
`dialog_class` (for example `NPC.happy`) to preserve the full class, mode, and
attitude. A unit takes text OR `template`, never both. `template` is an explicit
Python-native Jinja escape hatch using `reference(host)` / `introduce(host)`;
it evaluates once and does not recursively execute syntax generated by names.
Block `choice_labels` maps explicit action labels to the same references but
forbids introductions.

Ordinary Block.content and non-opted-in prose stay unchanged. The new `linked`
scene separately enables the bounded runtime
frontend described below; ordinary Block.content is not migrated.

The alternate start choice demonstrates the explicit authored mutation form:
`pre_effects: ["introduce(host)"]` identifies before turn prose. Non-printing
template calls use `{% set _ = introduce(host) %}`; the shared mu-block renderer resolves its
speaker before evaluating the utterance, preserving that utterance's earlier
display label. Names such as Nanae in literal speech are not rewritten or
treated as introductions.

Ordinary raw/Jinja dialog labels also read the adopted naming policy, but bind
at composition after the whole block has evaluated. A raw mid-body introduction
can therefore name both labels in that block. Use ordered authored mu-blocks when
the current label must stay anonymous and only subsequent labels become named.

Fresh-process JSON service restore must bootstrap the world normally with
`manager.open_world("concept_naming_demo")` before opening the saved session.
Reopening a manager within the same process is not a World/authority reset.

Parsing callout content with DialogHandler produces the same authored vocabulary,
without fetching names/media. Rendering returns fresh fragments and never binds
back onto graph-owned source values. Stored units use the existing constructor-
form embedding path, not a prose-specific serializer. Automatic lexical linking
is not part of the foundation itself; the opt-in runtime adapter now supplies it
without replacing explicit references and effects.

The shared `prepare_fragment` seam resolves metadata before body evaluation;
MuBlockHandler.render completes ordered realization. Structured speaker labels
are strict namespace symbols: `host_role` resolves to its current Actor before
name, identity, style or media are read, while attribution retains `host_role`.
Missing/unbound symbols fail before the body. Ordinary callout display labels
keep their existing fallback. Custom stored variants must appear explicitly in
the owning prose-field annotation with both persistence markers; a global type
registry or owner pointer on each mu-block is unnecessary.

The optional vocabulary now uses `NamedConcept`, `NamedActor`, and
`NamedLocation`. Rin is a `PersonalNamedActor` with an optional embedded
`PersonalName`; basic named actors do not require name parsing. `adopts()` returns
plain spelling-to-parameter data. `reference(host, form="formal")` requests
"Ms. Northstar", but AUTO still says "the blonde girl" while she is unknown.
`reference(host, "proper", form="formal")` forces that wording without disclosure.
Only `introduce(host)` changes knowledge. Proper aliases/forms can override the
generated data; anonymous descriptions are not automatically adopted.

The later scene uses the same contract on a plain graph-owned `NamedSword`:
"You find an old sword", then an explicit inscription introduction, then
"You carry Dawnblade". The domain creates it from an EntityTemplate at story-ready
and nominates only `sword` into scope, not all graph objects. A named object is
eligible for references/introductions, not automatically a dialog speaker.
Portable references accept `params: {form: inscription}` without Jinja; the
Python helpers accept the same keyword data. Normal JSON world bootstrap restores
personal names, reference parameters, object knowledge and historical output.

## Opted-in raw narration

Choose "Read linked narration" from a fresh story, or run the extended CLI witness.
The world defaults `link_prose` to false, while the `linked` scene sets
`locals: {link_prose: true}`. A nearer block can set it false again. Naming policy
does not enable lexical linking, and explicit parts/templates work with it off.

Plain MuBlock string text can mix narration and the existing Obsidian callouts:

```yaml
prose:
  - text: |
      Rin waits at Market Square beside Dawnblade.

      > [!npc.excited] host_role
      > This is my sister, Nanae. Rin #intro stays spoken.

      Nanae #intro smiles. Nanae waves. Rin#intro nods.
```

Narration names lower to AUTO references from current gathered scope, including
the scene's ancestor bindings and the world's explicitly nominated sword. Proper
forms (e.g. `Dawnblade of the East`) retain scalar form intent without forcing
knowledge. `NAME#intro` or `NAME #intro` identifies at that ordered position.
Speech stays literal/non-disclosing, and labels resolve purely before bodies.
The later passage remembers actor/place/sword; the existing semantic choice label
sees Rin's introduction without changing the edge identity.

Matching is exact, case-sensitive and longest-first with complete word boundaries;
`Ringo` is not Rin. Anonymous descriptions are literal by default. Complete
`#intro` is required: `#introvert`/`#introduction` are not markers. Punctuation after
a marker remains; punctuation/newlines before it cannot attach it. Unmatched
complete markers and encountered ambiguities report owner/source/unit/offset.
Escape a name and its adjacent marker with `\Rin #intro`, or escape a standalone
marker with `\#intro`. Slash pairs emit one slash, so `\\Rin #intro` links normally
with one literal slash. Unrelated slashes stay unchanged. Inline/fenced code stays
literal; unclosed fences protect their remainder. Explicit templates and text
units containing Jinja delimiters are entirely opaque to linking. Split mixed
source/templates into separate ordered units; generated text is never rescanned.

Source strings stay authored in the graph and across constructor/JSON restore;
linked units are ephemeral and use the same renderer. Custom structured mu-blocks
keep their preparation methods/types, while custom raw callout syntax remains
that type's responsibility. Discovery never scans the graph/catalog, provisions,
or creates knowledge. Previously lowered symbols follow recasting, but rebuilding
discovery uses the replacement's spellings, not stable aliases of the old actor.
Stable binding-owned names, broader Block.content linking, #558 destination labels,
NLP and failed-traversal recovery remain separate. #557 remains untouched salvage.
