# Grand Grotto

A Colossal Cave-inspired sandbox demo of movement, light, inventory, and
spatial affordances. Start the `adventure_sandbox_slice` world in a StoryTangl
client.

The world loads asset definitions as a catalog before any story is created. Each
story owns its tokens, holder wallets, and shared grate. A JSON-backed Service
witness restores room, player, and cage custody in a fresh process, continues
through ordinary choices, and traverses the same open grate in both directions.
The carried lamp retains its state and participates in the existing darkness rule.
