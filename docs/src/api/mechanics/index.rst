Mechanics package notes
=======================

The package design notes below are kept beside the code in
``engine/src/tangl/mechanics`` and included here unchanged. They are the long form of
the package docstring: purpose, contracts and status. They connect the conceptual
and planning pages under *Design* to the reference that follows.

Mechanics are optional families that extend story concepts and episodes. For
the conceptual survey of each family see :doc:`../../mechanics/index`.
