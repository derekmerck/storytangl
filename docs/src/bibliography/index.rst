Bibliography
============

The project's reference library: narrative theory, interactive-fiction patterns,
algorithms and formal methods, authoring systems and format specifications, and
the games and gamebooks used as executable witnesses.

``storytangl.bib`` is a copy of the project Zotero library. Change entries in
Zotero and re-export; do not edit the copy by hand. Cite a work from any page
with its key:

- reStructuredText: ``:cite:`chatman_story_1978```
- MyST Markdown: ``{cite}`chatman_story_1978```

Files outside this documentation tree, such as READMEs, cannot use those roles.
``scripts/mini_bib.py`` prints a Markdown reference list for a set of keys or
keywords, to paste at the bottom of such a file.
